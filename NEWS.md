# TDecisionCodigo 0.3.1

## Development changes

* `multicriterio.metodoAHP.variante3.completo()` now obtains the alternative
  names (level 2) consistently instead of from the last slice of the level-2
  array, which was always `NULL` because R does not propagate rownames when
  slices are assigned to a 3D array. As a result, the returned table
  (`pesos.globales_entabla`) and `pesos.globales` now always carry alternative
  names (taken from the array `dimnames`, the first level-2 matrix, or
  autogenerated as `a1`, `a2`, ... when none are available).
* Extended and fixed documentation examples for the multicriteria functions:
  `indice.prefmulticriterio()`, `flujo.entrante.Promethee()`,
  `flujomed.entrante.Promethee()` and
  `multicriterio.metodoAHP.variante3.completo()` now include runnable
  examples in their help pages; added `@seealso` cross-references between
  related functions (AHP variants, ELECTRE I / libro variant, TOPSIS classic /
  modified, Promethee I / II, Arrow-Raymond / matriz de clasificación).
* README: installation from CRAN moved to the end of the Installation section,
  since the package is not published on CRAN yet; GitHub is now the primary
  installation source.

## Bug fixes

* `dibuja.criterio.Hurwicz_Intervalos()` no longer fails with
  `uniroot` when two consecutive optimal alternatives do not cross within
  `[0, 1]` (e.g. alternatives with identical range). The root search is now
  wrapped in `tryCatch` and pairs without a sign change are skipped. The case
  where a single alternative is optimal throughout `[0, 1]` (no cut point) is
  also handled, returning a single interval `(0, 1)` instead of `NA`.
  Fixes issue #22.

## Development changes (issue #21)

* `multicriterio.metodoAHP.variante3.completo()` now returns a new element
  `Calculos` with the intermediate results (`pesos.nivel1`, `l.pesos.nivel2`,
  `m.pesos.nivel2`, `nombres.alternativas`, `nombres.criterios`,
  `pesos.globales.ordenados`, `orden.alternativas`), so reports can access
  the details without printing the full output. The alternatives are ordered
  from highest to lowest global weight.
* New function `multicriterio.metodoAHP.variante3.completo_tinytable()`
  builds `tinytable` tables from the AHP results: global weights (sorted),
  local weights per criterion, and inconsistency (RI) per level. The tables
  render natively in Quarto documents to HTML, Typst/PDF or LaTeX.

# TDecisionCodigo 0.3.0

## New features

* New function `multicriterio.metodo.mediaPonderada()` implements the weighted
  mean indicator method: the valuation matrix is homogenised with the Nadir
  method, weighted with the criterion weights and the alternatives are
  ranked by the sum of their weighted valuations.
* `func_calcula_matrizclasificacion()` and
  `multicriterio.metodoaxiomatico.ArrowRaymond()` accept a new optional
  `pesos` argument, so the Arrow-Raymond axiomatic method can now be applied
  with weighted criteria. The unweighted result is unchanged.
* New file with the multicriteria graphics: `plot_promethee_I()`,
  `plot_barras_vector()`, `plot_lineas_rangos()`,
  `plot_barras_acumuladas_rangos()`, `plot_segmentos_rangos()` and
  `plot_barras_acumuladas_Mvaloraciones()`, all built with 'ggplot2' and
  'ggrepel'.
* New function `func_tabla_rangos_metodos()` builds the long table of ranks
  per method that the range comparison plots use.

### Development changes

* `multicriterio.metodoAHP.variante3.completo()` now obtains the alternative
  names (level 2) consistently instead of from the last slice of the level-2
  array, which was always `NULL` because R does not propagate rownames when
  slices are assigned to a 3D array. As a result, the returned table
  (`pesos.globales_entabla`) and `pesos.globales` now always carry alternative
  names (taken from the array `dimnames`, the first level-2 matrix, or
  autogenerated as `a1`, `a2`, ... when none are available).

# TDecisionCodigo 0.2.0

## New features

* New functions `multicriterio.metodo.topsis()` and
  `multicriterio.metodo.topsis_modificado()` implement the classic and
  modified TOPSIS methods, with presentation helpers
  `multicriterio.metodo.topsis_tinytable()` (native Typst, HTML and LaTeX
  tables) and `multicriterio.metodo.topsis_grafico()` (relative-closeness
  bar chart).
* New functions `multicriterio.metodo.promethee_windows_tinytable()` and
  `multicriterio.metodo.promethee_windows_tinytable_exportar()` build the
  Promethee Windows tables with the 'tinytable' package. The objects returned
  by the first one adapt automatically to the output format (HTML, Typst or
  LaTeX) and the second one writes the tables to PNG, Typst, HTML or PDF
  files.

## Development changes

* `multicriterio.metodoAHP.variante3.completo()` now allocates the list of
  second-level weights according to the number of criteria, so AHP hierarchies
  with different numbers of criteria and alternatives are handled correctly.
* The row groups of the Promethee Windows scenario table ("Preferencias",
  "Estadisticas" and "Evaluaciones") are now computed from the actual content
  of the table, so they are also correct when the `fminmax` argument is not
  used (in that case the preferences block has five rows instead of six).

# TDecisionCodigo 0.1.0

## New features

* First CRAN-ready release as an 'R' package.
* Decision under uncertainty: Wald, Optimistic, Hurwicz (including interval
  analysis), Savage, Laplace, Ideal Point and joint summary.
* Multicriteria: value-function construction, Nadir and Promethee
  homogenisation, Analytic Hierarchy Process (three variants, global weights,
  inconsistency), ELECTRE I (two variants), PROMETHEE I and II (sum and mean
  flows), GAIA plane and Arrow-Raymond axiomatic method.
* Bayesian trees: joint, marginal and posterior distributions, prior and
  posterior expected values, REII, RER, VEX, VEIP, entropy and channel
  information, complete benefit/cost and entropy studies.
* Full roxygen2 documentation with runnable examples and 'testthat' coverage
  for core calculations.
